# 校园活动管理系统 V2.0

## 运行

直接用浏览器打开 `index.html`。数据保存在当前浏览器 localStorage。首次可在登录页点击“载入一套演示数据”；演示账号 teacher / student，密码均为 123456。教师账号发布活动时可填写参加条件；留空表示无条件。

## 报名规则

- 无条件且有名额：提交后直接确认。
- 无条件但已满：进入候补，按进入时间先后排列。
- 活动填写参加条件：申请先进入待审核；教师逐个审核，不符合则结束申请，通过后有空位即确认，否则进入候补。
- 只有已确认参加占用名额。已确认学生在报名截止前取消会释放名额，最早候补转为已确认。
- 学生在“我的报名”查看已确认、待审核、候补位置；截止前可取消申请或候补。

## 约束

系统仅更新浏览器内的报名状态，不提供站外通知或候补响应时限。上述细节及管理员可编辑的活动字段仍需后续访谈确认。管理员未获得教师活动资格审核权限。
