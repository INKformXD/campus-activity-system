# 校园活动管理系统 V3.0

实验三在实验二 V2.0 原工程上迭代。业务链：
**教师发布活动 → 学生申请 →（有条件时教师审核）→ 确认或候补 → 取消后候补队首补位**。
V3.0 在这条链上补充"状态可见性"：报名结果有回执、候补队列可查、状态变化有消息。

## 运行方式

无需安装任何环境，直接用浏览器（Chrome / Edge）双击打开 `index.html` 即可。

- 打开后可点击登录页下方「载入一套演示数据」，获得演示账号：
  - 教师：`teacher` / `123456`
  - 学生：`student` / `123456`
- 也可自行注册新账号（注册时选择「学生」或「活动组织教师」身份）：
  - 学生注册无需额外验证；
  - **教师注册须输入教师认证码（演示环境固定为 `JS2026`）**，防止随意注册教师身份并发布活动；
- 登录后可在导航栏「注销账户」删除本人账号及其关联数据（教师：其发布的活动与相关报名；学生：其报名记录与消息），该操作不可恢复。

> 数据保存在浏览器 localStorage 中，清除浏览器数据会丢失。本系统为教学原型，没有服务端，因此消息只在再次打开本浏览器时可见，不提供跨设备实时推送。

## V3.0 变更（本轮新增）

1. **报名回执与幂等提交**：提交后弹窗给出状态、回执号与下一步入口；提交期间按钮禁用并显示「提交中…」；同一学生对同一活动重复提交返回同一条记录与同一回执号，不再产生重复申请。
2. **候补队列透明化**：我的报名显示「候补第 N 位 / 共 M 人」，状态变化后卡片标出「有新变化」与最近变化时间。
3. **站内消息中心**：报名结果、教师审核结果、候补补位都会生成消息，导航栏显示未读数；打开消息即标记已读并持久保存在浏览器中。

## V2.0 既有能力（保持不变）

- 参加条件留空：有空位直接确认；满员时按进入时间加入候补。
- 填写参加条件：教师逐一审核；通过且有空位时确认，通过但满员时加入候补。
- 只有已确认报名占用名额；已确认者取消后候补队首转为已确认。
- V1.0 能力：注册登录（教师须认证码）、注销账户与级联清理、活动发布与校验、浏览与详情、报名规则、我的报名与取消、名单查看、关闭/重新开放报名。
