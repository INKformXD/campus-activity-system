# 校园活动管理系统 V2.0

实验二在实验一 V1.0 原工程上迭代。业务链：
**教师发布活动 → 学生申请 →（有条件时教师审核）→ 确认或候补 → 取消后候补队首补位**。

## 运行方式

无需安装任何环境，直接用浏览器（Chrome / Edge）双击打开 `index.html` 即可。

- 打开后可点击登录页下方「载入一套演示数据」，获得演示账号：
  - 教师：`teacher` / `123456`
  - 学生：`student` / `123456`
- 也可自行注册新账号（注册时选择「学生」或「活动组织教师」身份）：
  - 学生注册无需额外验证；
  - **教师注册须输入教师认证码（演示环境固定为 `JS2026`）**，防止随意注册教师身份并发布活动；
- 登录后可在导航栏「注销账户」删除本人账号及其关联数据（教师：其发布的活动与相关报名；学生：其报名记录），该操作不可恢复。

> 数据保存在浏览器 localStorage 中，清除浏览器数据会丢失。

## V2.0 变更

- 参加条件留空：有空位直接确认；满员时按进入时间加入候补。
- 填写参加条件：教师逐一审核；通过且有空位时确认，通过但满员时加入候补。
- 只有已确认报名占用名额；已确认者取消后候补队首转为已确认。学生可在“我的报名”查看状态和候补位置。
- 访谈未确认站外通知、候补响应时限和管理员可改的具体活动字段，因此未实现。

## V1.0 保留范围

- 纳入：注册登录（学生/教师，教师注册须认证码验证）、注销账户（级联清理数据）、活动发布与信息校验、活动浏览与详情、在线报名（重复报名/名额/截止/必填校验）、我的报名与取消、报名名单查看、关闭/重新开放报名。
- 不纳入（后续迭代候选）：注册确认密码（防误输辅助功能，已取舍）、消息推送、现场签到、评论评分、海报上传、管理员代替教师审核、统计报表、找回密码。
