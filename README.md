# 校园活动管理系统 V1.0

实验一「基于工程意图的软件迭代开发」配套项目。V1.0 打通核心业务链：
**教师发布活动 → 学生浏览并报名 → 教师查看报名名单、管理报名状态 → 学生查看/取消本人报名**。

## 运行方式

无需安装任何环境，直接用浏览器（Chrome / Edge）双击打开 `index.html` 即可。

- 打开后可点击登录页下方「载入一套演示数据」，获得演示账号：
  - 教师：`teacher` / `123456`
  - 学生：`student` / `123456`
- 也可自行注册新账号（注册时选择「学生」或「活动组织教师」身份）：
  - 学生注册无需额外验证；
  - **教师注册须输入教师认证码（演示环境固定为 `JS2026`）**，防止随意注册教师身份并发布活动；
- 登录后可在导航栏「注销账户」删除本人账号及其关联数据（教师：其发布的活动与相关报名；学生：其报名记录），该操作不可恢复。

> 数据保存在浏览器 localStorage 中，清除浏览器数据会丢失。

## 目录结构

```
├── index.html        页面骨架
├── css/style.css     样式
├── js/storage.js     数据访问层（localStorage 封装）
├── js/auth.js        注册、登录、会话、密码哈希
├── js/app.js         视图渲染与业务规则
└── docs/
    ├── 需求文档.md    用户故事、V1.0 需求基线、需求取舍、业务规则
    └── 设计文档.md    工程意图、总体设计、数据设计、关键设计决策
```

## V1.0 范围

- 纳入：注册登录（学生/教师，教师注册须认证码验证）、注销账户（级联清理数据）、活动发布与信息校验、活动浏览与详情、在线报名（重复报名/名额/截止/必填校验）、我的报名与取消、报名名单查看、关闭/重新开放报名。
- 不纳入（后续迭代候选）：注册确认密码（防误输辅助功能，已取舍）、消息推送、现场签到、评论评分、海报上传、管理员审核、统计报表、找回密码。
